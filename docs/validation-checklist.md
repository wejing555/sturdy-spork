# 工程出图核验清单

## 来源

- [ ] 规范/图集名称已确认。
- [ ] 版本或年份已确认。
- [ ] 条文号和页码可回查。
- [ ] 使用的是项目实际原始文件，而不是文件名或历史方案推断。

## 参数

- [ ] 障碍物类别已确认：梁、风管、管道、桥架等。
- [ ] 宽度、标高、底标高和完成面已确认。
- [ ] 喷头型号、标高、间距及管道关系来自正式图纸或经确认的深化图。
- [ ] 未确认参数均标记为“待核”，没有默认值。

## 几何与表达

- [ ] 平面图与剖面图表达的是同一组参数。
- [ ] 尺寸线、方向、标高和单位明确。
- [ ] 图例、线型、文字和比例满足项目制图要求。
- [ ] 生成图没有把示意关系误写成施工做法。

## 发布

- [ ] DXF/SVG/PDF 已打开检查。
- [ ] 规则文件、来源记录和输出文件版本一致。
- [ ] 经专业负责人/设计单位要求的复核已完成。
